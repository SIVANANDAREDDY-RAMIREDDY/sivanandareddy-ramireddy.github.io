SWPC: Smart Water Pump Controller

Simulation Environment: Circuit Designer IDE / Proteus VSM

Operation Flow: Conductive sensor probes read fluid high/low status into an MCU input port. Digital debounce filters eliminate false triggers from fluid surface ripples. A transistorized relay driver activates an AC pump contactor while maintaining electrical isolation.

[Sensor: Low] -> MCU P1.0 High -> Opto-Coupler -> Relay Latched -> Motor RUN
[Sensor: High] -> MCU P1.0 Low -> Relay Cutoff -> Overflow Halted

Paper: Presented at SAMSLESHANA-2K26 (AITS Kadapa, Feb 2026).

FSPG: Foot Step Power Generator

Simulation Environment: Proteus Design Suite

Stages: Transduction stage uses piezoelectric / dynamo inputs to capture kinetic impacts. Alternating current spikes are converted via a Schottky full-bridge rectifier, smoothed with capacitor reservoirs, and clamped by a LM7805/DC-DC buck regulator to supply 5V DC for rechargeable battery banks.

Impact Force -> AC Pulse -> Bridge Rectifier -> Filtering -> DC Voltage Reg -> Storage
